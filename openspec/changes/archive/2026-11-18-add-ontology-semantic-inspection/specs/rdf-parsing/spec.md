# Spec Delta

## MODIFIED Requirements

### Requirement: 解析资源上限与诊断聚合

解析 SHALL 施加可配置资源上限：单条字面量值长度上限（超限时保留被限定的原始语句身份材料，提供有界的保留/显示值，并产生 `literal-limit` 诊断与截断标记）、嵌套深度上限（超限时停止该分支、保留已解析结果并产生 `nesting-limit` 诊断）、原始诊断消息条数上限（超限后继续计数并产生 `diagnostics-truncated` 诊断）。语义字面量身份 MUST NOT 由 UI 显示摘要或截断前缀单独生成；无法在配置的身份预算内可靠判等时 MUST 标记身份不可靠，且 MUST NOT 以此身份去重。原始身份材料 SHALL 使用有界存储；任何预算耗尽都 MUST 公开不确定性，不得关闭全部输入限制或静默发生。诊断 MUST 按 code 聚合，包含 `count` 与最多 3 条样本。

#### Scenario: 超长字面量的语义身份与显示摘要分离

- **WHEN** 单条 literal 超过字面量显示长度上限
- **THEN** 解析结果保留受资源预算保护的判等材料或其可靠摘要、原始长度、`dt`/`lang` 和截断状态；显示层只消费有界摘要，且不得把摘要当作 RDF 词法值

#### Scenario: 相同截断前缀的不同长字面量

- **WHEN** 两个不同长字面量具有相同的显示截断前缀
- **THEN** 解析身份层不得仅凭该前缀判为相等；若可靠判等材料未能保留，身份标为不可靠且调用方不得合并二者

#### Scenario: 完全相同的长字面量

- **WHEN** 两条长度超过显示预算但 RDF 词法值、datatype、language 和图身份完全相同的语句被解析
- **THEN** 只在身份材料能可靠证明相等时返回相同语义身份，否则分别保留并标记无法可靠判断；无论如何不得误合并不同语句

#### Scenario: 超过身份材料预算

- **WHEN** 长 literal 的身份计算或有界身份材料达到配置预算
- **THEN** 解析保留安全的显示摘要与截断诊断，将相等性标记为 unknown，不继续无界累积原值，且不得把 unknown 当成相等

#### Scenario: 既有字面量长度上限

- **WHEN** 输入达到或超过字面量长度预算
- **THEN** 上限触发语义与严格超限情形一致，保留确定的边界标记、计数和身份可靠性状态；解析和后续分析不得把边界摘要解释为完整词法值

#### Scenario: 超长字面量被截断

- **WHEN** 单条字面量值超过长度上限
- **THEN** 该值按上限截断并带截断标记，产生 `literal-limit` 诊断，解析继续并返回部分结果

#### Scenario: 超深嵌套保留部分结果

- **WHEN** 输入嵌套深度超过上限
- **THEN** 解析停止该分支并返回已解析的部分结果，产生 `nesting-limit` 诊断，不发生未捕获异常或整份结果丢失

#### Scenario: 诊断洪泛被聚合

- **WHEN** 输入产生超过上限数量的原始诊断消息
- **THEN** 诊断按 code 聚合，原始消息只保留上限数量与每个 code 最多 3 条样本，并产生 `diagnostics-truncated` 诊断，视图不逐条渲染全部消息
